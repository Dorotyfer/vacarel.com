# Alcance y catálogo de pantallas

Cada pantalla operativa incluye búsqueda, filtros, detalle, historial y acciones sujetas a permiso. Los documentos confirmados se corrigen por operaciones vinculadas; los maestros con historial se desactivan en lugar de eliminarse.

| Área | Pantallas y capacidades |
|---|---|
| Panel | Ventas, cobros, deuda vencida, mínimos, vencimientos, pedidos y entregas pendientes según permisos |
| Productos | Catálogo, ficha, categorías, marcas, códigos alternativos, presentaciones, equivalencias, IVA, mínimos, listas y cambios de precio |
| Compras | Proveedores/contactos, solicitudes, cotizaciones comparadas, órdenes, recepciones parciales, diferencias, facturas y devoluciones |
| Inventario | Existencias, ubicaciones, movimientos, reservas, transferencias, conteos, solicitudes de ajuste y mermas |
| Lotes | Ficha, recepciones originales, vencimientos, cuarentena, bloqueo y trazabilidad hasta clientes |
| Clientes | Identificación, direcciones, zona, vendedor, lista de precios, crédito, historial y cuenta corriente |
| Colaboradores | Ficha, clientes asignados, usuario opcional y configuración histórica de comisión |
| Ventas | Pedidos, líneas, crédito, descuentos autorizados, reservas y seguimiento |
| Reparto | Preparación FEFO, verificación, despacho, hoja de ruta, repartidor, entregas, rechazos y rendiciones |
| Facturación | Autorizaciones, rangos, documentos, plantilla, intentos de impresión, reimpresiones y anulaciones |
| Cobranzas | Saldos, vencimientos, recibos, aplicaciones, anticipos y rendiciones |
| Pagos | Deudas, vencimientos, anticipos, órdenes de pago, aplicaciones y comprobantes |
| Tesorería | Cajas, sesiones, cuentas bancarias, movimientos, gastos, arqueos y conciliación manual |
| Comisiones | Configuración por persona, devengamientos, ajustes, revisión, aprobación, liquidación y pago |
| Administración | Usuarios, roles, permisos, aprobaciones, auditoría, parámetros y respaldos |
| Informes | Filtros, consultas, exportación CSV e impresión |

Los lectores que emulan teclado podrán ingresar códigos en búsquedas. Cámara, GS1 y serialización individual no forman parte del alcance confirmado.
