# Desarrollo inicial

Entrega ejecutable del núcleo: instalación CLI, autenticación y CSRF, permisos en servidor, productos, clientes, proveedores, colaboradores, recepción por lote, movimientos, panel y auditoría. PHP sin framework, frontend vanilla, MariaDB. Sin datos ficticios ni emisión fiscal.

Secuencia: escribir pruebas de recepción/conversión/idempotencia/permisos; comprobar fallo; implementar esquema y servicio; implementar API y vistas; ejecutar pruebas y sintaxis; verificar HTTP con sesiones y CSRF. Las siguientes entregas incorporarán órdenes, reservas, despacho, tesorería y documentos fiscales sobre este núcleo.
